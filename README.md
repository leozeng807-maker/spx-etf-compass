# 标普四象

SPX、513650、159655、513500 的方向概率、预计涨跌幅和三 ETF 同资金交易沙盘。

本仓库只保存编译后的网页；开发源码、实时计算接口、D1 数据库和历史模型快照保存在云端项目中。

- 每次打开页面或点击刷新按钮时，云端接口实时抓取行情并重新计算。
- 长历史数据按周生成统计快照，访问页面时直接读取快照，不重复下载十年明细。
- 四项资金数据保存在 Cloudflare D1；电脑和微信打开同一链接时读取同一份最新值。
- 工作日收盘后记录正式预测，到期后累计方向命中率和涨跌幅误差。

当前版本是单一共享账户，没有登录和用户隔离；知道页面地址的人可能读取或修改资金数据，请勿分享链接，也不要填写身份、账号等敏感信息。公开行情和 QDII 净值可能延迟，所有结果仅供研究交流，不构成投资建议或收益承诺。
